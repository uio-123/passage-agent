# P4 E5：运行指标与管理治理视图

状态：已完成  
依赖：既有 `agent_log`、P4 E1 事件和现有管理员统计页。  
范围：基于已持久化的安全日志字段提供管理员聚合指标与慢节点/失败率告警；不从 `prompt/inputData/outputData/errorMessage` 聚合或输出敏感内容。

## 指标口径

| 指标 | 可信数据源 | 缺失处理 |
|---|---|---|
| 执行量、成功率、失败率、平均耗时、P50/P95 | `agent_log.status/durationMs` | 无日志为 0；分位数按已完成且 duration 非空样本计算 |
| 慢节点/高失败 Agent | 同上，按 agentName 聚合 | 仅返回名称、计数、耗时/失败率，不返回错误原文 |
| Token、首 Token、模型、估算成本、重试 | 当前没有完整可信持久化字段 | API 显式返回 `available=false`，页面显示“未采集”；禁止用正文长度或估算值冒充真实数据 |

## API 与 UI

- 新增仅管理员可访问的 `GET /api/statistics/agent-governance`，返回全局安全聚合、按 Agent 的慢/失败候选及未采集指标说明。
- 管理端在既有统计页增加治理卡片/表格。告警为只读启发式提示：`failureRate >= 10%` 或平均耗时位列前列，不触发外部通知。
- 统计查询限定可配置窗口（默认近 30 天）和最大样本，避免后台全表扫描；不回传 `agent_log` 原始记录。

## 测试与回滚

- 单元：分位数、失败率、无样本、敏感字段隔离。
- MVC：非管理员拒绝、响应无 prompt/input/output/errorMessage。
- 前端：未采集 Token/成本不显示为零成本，空数据正确渲染。
- 回滚只隐藏管理端治理面板/API；日志和 P4 其他阶段不受影响。

## 实施结果

- 新增管理员专用治理 API 和管理端面板，聚合最多 10,000 条日志的执行量、成功率、平均耗时、P50/P95、慢 Agent 和高失败 Agent。
- 统计查询和响应均不返回 Agent Log 的 Prompt、输入、输出或错误正文；Token、成本、首 Token 以未采集状态返回。
- 后端编译和前端类型检查通过。
